Portal — architektura shadera (v2)

Dodano warstwę Twirl przed próbkowaniem noise

Przybliżony wygląd

1 Circular Alpha Mask

SDF okręgu — tnie quad do kształtu portalu.

2 Twirl UV Distortion ✦ nowe

Node Twirl wbudowany w Shader Graph. Wykręca UV spiralnie wokół centrum. Parametry: _TwirlStrength (głębokość skrętu) i _TwirlOffset (animowany przez PortalAnimator → DOTween).

3 Swirl Vortex (Noise + Polar UV)

Noise próbkowany na wykręconych UV → organiczny ruch wiru.

4 Color Gradient (Center → Edge)

3 konfigurowalne kolory: _ColorCenter, _ColorMid, _ColorEdge.

5 Sparkle Dots

Voronoi + threshold → białe iskierki przy krawędzi.

6 Edge Glow (Emission HDR)

Bloom przez URP Post Processing.

PortalAnimator.cs — nowe property
_TwirlStrength // float — siła skrętu
_TwirlOffset   // float — animowany w czasie → daje ruch
_ScrollSpeed  // float — prędkość przewijania noise
_Intensity    // float — jasność/bloom
_OpenAmount   // float 0–1 — animacja otwarcia portalu
